============================================================
六份新的 BehaviorSpace Table CSV → 七份独立 Python 分析 → 与原 HTML 内嵌参考逐场核对。
第 0 组复用第 1 组的基准；费用组为实际重跑，并独立验证重计价。

90 场 / 3 个条件；核对状态：pass
合作 1 家：平均满足率 63.20%；平均总开支 17484311.52；平均单位开支 140.59。
合作 2 家：平均满足率 84.00%；平均总开支 24683112.51；平均单位开支 149.64。

3 家减 2 家：满足率 +11.18 个百分点，95% CI [7.80, 14.56]；单位开支 +7.82，95% CI [7.03, 8.61]。
第 0 组是统一基准的汇总，90 场来自第 1 组，不是新增的独立实验。更多伙伴的服务优势必须与其单位开支一起解释，不能据此选择利润最优策略。

第 1 组：断供风险
270 场 / 9 个条件；核对状态：pass
合作 1 家，风险 0/2/5% 的满足率依次为 69.66 / 63.20 / 55.20%。
合作 2 家，风险 0/2/5% 的满足率依次为 90.79 / 84.00 / 74.40%。
合作 3 家，风险 0/2/5% 的满足率依次为 99.67 / 95.19 / 86.52%。
三种策略均随风险升高而降低满足率。
风险为 0 时，单供应商满足率仍为 69.66%，因此无断供时已存在供应/分配限制，不能把多元采购的全部收益都称为抗断供收益。
2% 是正常供应商当期新故障概率；实际断供暴露为 10.007% 的供应商周期。持续故障会使暴露比例高于新发概率。

第 2 组：供应商产能
540 场 / 18 个条件；核对状态：pass
产能基准 60：无断供时 k=1/2/3 的满足率为 47.85 / 64.11 / 73.62%；风险 2% 时为 43.31 / 58.13 / 66.64%。
产能基准 80：无断供时 k=1/2/3 的满足率为 59.74 / 79.79 / 92.06%；风险 2% 时为 54.06 / 72.78 / 84.69%。
产能基准 100：无断供时 k=1/2/3 的满足率为 69.66 / 90.79 / 99.67%；风险 2% 时为 63.20 / 84.00 / 95.19%。
基准产能 60/80/100 的平均实际总产能/总需求为 0.767 / 1.023 / 1.278。60 时总量不足；提高伙伴数不能凭空增加供货能力。
产能基准 100、无断供、单供应商时，平均闲置可用产能 229.1 单位/周期，同时满足率仅 69.66%。这支持固定合同下的分配拥堵解释。闲置产能不代表当前客户都能通过既有合同调用它。

第 3 组：库存目标
540 场 / 18 个条件；核对状态：pass
风险 2%、三供应商：目标 0/1/2 的满足率为 84.93 / 95.19 / 96.68%；实际平均库存为 0.4 / 170.2 / 421.7。
目标 1−0：服务增加 10.26 个百分点，95% CI [8.77, 11.75]；目标 2−1：增加 1.50，95% CI [1.26, 1.73]。
第二份目标的服务增益较小，同时带来更高实际库存；这是当前参数范围的边际比较。
无断供、三供应商时，目标 1−0 的服务增益仍为 8.57 个百分点。目标会进入补货公式 Q=max(0,D+T−I)，因此实验同时包含补货政策作用和库存缓冲。
风险 2%、单供应商的目标 0/1/2 满足率为 62.66 / 63.20 / 63.59%，库存目标不能替代持续的供给能力。
所有目标使用相同初始库存；目标 0 不是初始库存 0。报告一处正文把 63.585… 写成 63.58，按两位小数四舍五入应为 63.59；原报告表格及原始数据一致。

第 4 组：运输系数
270 场 / 9 个条件；核对状态：pass
合作 1 家，在运费系数 2/3/4 下满足率为 57.75 / 63.20 / 68.02%。
合作 2 家，在运费系数 2/3/4 下满足率为 75.54 / 84.00 / 87.18%。
合作 3 家，在运费系数 2/3/4 下满足率为 92.86 / 95.19 / 96.07%。
单供应商的单位开支从系数 2 时的 130.62 增至系数 4 时的 150.35。
三供应商的平均满足率在三档运费下均最高。
运费在初始化选商前进入到货成本，所以会改变合作网络、份额和运输账单。服务变化不能解释为单纯把同一批交付的运价调高；这是地理权重变化下的模型比较，不是真实运价估计。

第 5 组：价格反馈
540 场 / 18 个条件；核对状态：pass
风险 2%、合作 1 家：alpha 0.20−0 的服务差 +0.000 个百分点，95% CI [0.000, 0.000]；单位开支差 +16.01，95% CI [15.42, 16.61]。
风险 2%、合作 2 家：alpha 0.20−0 的服务差 +0.161 个百分点，95% CI [0.126, 0.197]；单位开支差 +16.71，95% CI [16.26, 17.16]。
风险 2%、合作 3 家：alpha 0.20−0 的服务差 +0.126 个百分点，95% CI [0.087, 0.164]；单位开支差 +17.17，95% CI [16.74, 17.59]。
alpha=0.40 时，双/三供应商满足率为 84.13% / 95.28%。
当前反馈的服务改善很小，成本变化更大；统计区间可辨别的差异不代表业务影响很大。
单供应商在两档风险、30 个配对情景中，累计生产/交付、期末库存和库存总和均不受 alpha 影响。唯一伙伴无法通过报价改变订单份额，但采购账单会改变。

第 6 组：维护费与持有费
2430 场 / 81 个条件；核对状态：pass
全部 2,430 场费用重跑，与从该 CSV 的 270 条 F50/H1 基准轨迹重新计价一致。这里是实际运行次数，不是 2,430 个独立情景；每个条件仍只有 30 个配对情景。
重计价公式：采购费 + 运输费 + F × 合同数 × 500 + H × 各周期期末库存总和。该校验不使用历史报告的数据。
合作 1 家：目标 1、H=1 时，F=0/50/100 的单位开支为 138.48 / 140.59 / 142.70；目标 2、F=50 时，H=0/1/2 的单位开支为 140.39 / 141.05 / 141.70。
合作 2 家：目标 1、H=1 时，F=0/50/100 的单位开支为 146.56 / 149.64 / 152.71；目标 2、F=50 时，H=0/1/2 的单位开支为 149.73 / 150.44 / 151.15。
合作 3 家：目标 1、H=1 时，F=0/50/100 的单位开支为 153.44 / 157.46 / 161.48；目标 2、F=50 时，H=0/1/2 的单位开支为 157.44 / 158.54 / 159.64。
所有费用变体的生产、交付和库存结果一致。当前费用只参与记账，不会触发重新选商、减少伙伴或降低目标库存。
因此本组检验既定策略对费用假设的敏感程度；没有收入或缺货损失，不能推断经济最优策略。
